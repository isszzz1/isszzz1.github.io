- About Me

- Connect With Me

## Run locally
1. Open this folder in Visual Studio Code.
2. Make sure the Live Server extension is installed.
3. Right-click `index.html` and choose **Open with Live Server**. If the context-menu option is unavailable, open `index.html` and click **Go Live** in the VS Code status bar.
4. Save changes with `Ctrl + S`. Your browser should refresh automatically.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `professional-development-portfolio`.
2. Upload all files and folders in this project (not just the ZIP file).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will look like:
   `https://isszzz1.github.io/professional-development-portfolio/`

## Editing
- Edit text and sections in `index.html`.
- Edit colours, spacing and layout in `style.css`.
- Edit navigation behaviour in `script.js`.

Check every detail before publishing, especially your name, university programme, dates, GitHub username and email address.
